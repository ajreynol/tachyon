How to read this

A point below the dashed 10× line is not in the gap list at all; every point here is on or above it, or in the unsolved band. Times are user seconds for one run on one execution host, not repeated measurements, so small differences are noise. The z3 reference answers unknown on part of the corpus, and a benchmark it does not solve cannot enter this gap set however slow cvc5 is on it.
